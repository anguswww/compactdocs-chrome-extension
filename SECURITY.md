# Security

The current release line is 1.4.x. CompactDocs runs only on Google Docs document pages, stores three layout preferences locally, and has no analytics or extension-initiated network requests.

For a vulnerability or report containing private information, email angus.wwww@gmail.com. Include the extension version, Chrome version, and a minimal reproduction without credentials, access tokens, private document URLs, or document contents. Do not open a public issue with sensitive details.

Ordinary layout bugs can be reported in GitHub Issues. Google Docs UI changes and non-English interfaces may affect compatibility.
