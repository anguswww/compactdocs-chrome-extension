Local by design

Privacy policy

Applies to CompactDocs 1.4.1.

CompactDocs adjusts the Google Docs interface on your device. It does not collect document content, run analytics, or send data to a server.

What the extension processes

CompactDocs runs on Google Docs document pages matching https://docs.google.com/document/d/*. It examines the local page interface (the DOM), including control labels, panel state, layout dimensions, and view zoom, to locate native controls, compact the side panels, and fit paged documents to the available width.

This processing happens locally in your browser. The extension changes interface styles and local view zoom. It does not edit the document content, collect or store document text, or send document content elsewhere.

Three preferences, saved locally

The storage permission is used to save three preferences in chrome.storage.local:

  • Document tabs (collapseTabs): whether to keep the tabs tucked away.
  • Google side panel (hideRightPanel): whether to keep the side panel tucked away.
  • Fit page to window (fitToWindow): whether to fit paged documents to the window.

All three are enabled by default. These settings stay in the browser's local extension storage, not Chrome sync storage or an external server. You can change them in the toolbar popup. Removing the extension removes its local extension storage.

No collection or transmission

CompactDocs makes no network requests and has no analytics, advertising, tracking, or remote code. It does not collect, transmit, sell, or share personal data, browsing history, or document content. There is no CompactDocs account or server.

Where access is needed

The extension's content scripts are limited to the Google Docs document URL pattern above. They use that access to operate native panel controls, apply local layout styles, and adjust view zoom when fitting is enabled. They do not run on other websites or the Google Docs home page. The only declared extension permission is storage.

Google and other services

Google Docs continues to connect to Google as it normally does. Those connections are made by Google Docs, not CompactDocs. Google's handling of your account and documents is governed by Google's privacy policy.

This project website is intended for hosting on GitHub Pages, and downloads and source code are hosted on GitHub. GitHub may process normal service and request information under GitHub's privacy statement. These website and download services are separate from the extension, which makes no network requests. This website includes no analytics, cookies, or third-party embedded resources.

If the extension's behavior changes, this policy will be updated to describe it. Review this page alongside the version you install.
